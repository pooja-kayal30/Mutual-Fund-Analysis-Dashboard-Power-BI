📊 Mutual Fund Analysis Dashboard - Power BI
------------------------------------------------------------------------------------------------------------------------------------------
📌 Project Overview
------------------------------------------------------------------------------------------------------------------------------------------
This project focuses on analyzing a comprehensive dataset of mutual funds to extract meaningful insights related to performance, risk, and investment strategies. The analysis is supported by an interactive Power BI dashboard for better visualization and decision-making.
__________________________________________________________________________________________________________________________________________
📁 Dataset Description
------------------------------------------------------------------------------------------------------------------------------------------
The dataset contains detailed information about mutual funds, including:

• Fund Name (Scheme Name)

• Minimum SIP & Lumpsum Investment

• Expense Ratio

• Fund Size (in Crores)

• Fund Age

• Fund Manager

• Risk Metrics (Alpha, Beta, Standard Deviation)

• Performance Ratios (Sharpe, Sortino)

• Risk Level & Ratings

• Category & Sub-category

• Returns (1-Year, 3-Year, 5-Year)
__________________________________________________________________________________________________________________________________________
🎯 Objectives of the Project
------------------------------------------------------------------------------------------------------------------------------------------
• Analyze mutual fund performance based on returns

• Understand risk using financial metrics like Beta and Standard Deviation

• Compare funds across categories and ratings

• Identify top-performing and low-risk funds

• Build an interactive dashboard for easy interpretation
